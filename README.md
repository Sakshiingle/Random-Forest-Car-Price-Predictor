# Automobile Price Prediction

Machine Learning project that predicts the selling price of an automobile using a Random Forest Regressor.

## Dataset

Automobile Market Dataset

## Algorithm

Random Forest Regressor

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask

## Run

```bash
pip install -r requirements.txt

python app.py
```

Open

```
http://127.0.0.1:5000
```
